# Clima


**Clima** 
é um projeto criado com o objetivo de praticar e aprimorar habilidades em HTML, CSS e JavaScript. Ele simula um consultor do clima em várias cidades, estados, focando em boas práticas de codificação.

## 🔍 Visão Geral

- **Objetivo**: Praticar a interação do JavaScript com HTML5 e CSS3.
- **Tecnologias Utilizadas**:
  - HTML5
  - CSS3
  - JAVASCRIPT
- **Funcionalidades**:
  - Exibe os dados do tempo em diferentes cidades/estados do mundo.
  - Consumo de api.
  - Componentes reutilizáveis para facilitar a manutenção.
  - Organização de arquivos em pastas como `assets/`, `css/`, `js/`.
